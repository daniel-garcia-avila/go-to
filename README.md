# Go To

App web para planificar y gestionar viajes en familia.

- **Presupuesto y ahorro**: hucha del viaje con aportaciones y proyección de ahorro mensual.
- **Reservas y gastos**: vuelos, hoteles, transporte, actividades… con enlace, localizador y estado de pago.
- **Itinerario**: días con puntos de visita, enlaces a Google Maps y ruta del día.

Prototipo en un único `index.html` (sin dependencias). Los datos se guardan en el navegador (`localStorage`).

## Uso

Abre `index.html` en el navegador o publícalo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
